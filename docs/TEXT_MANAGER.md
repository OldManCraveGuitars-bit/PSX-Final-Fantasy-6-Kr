# FF6 한글 문장 관리기 v1.14

대사·이름·메뉴·전투·부록·영상 자막을 한곳에서 편집하고 화면 폭과 줄 간격을 검사하는 Windows용 EXE입니다. V0.76 번역 데이터 **7,720개 항목**을 함께 제공합니다. Python 설치는 필요하지 않습니다.

## v1.14 변경

문장이 칸 끝에 정확히 닿은 뒤 공백이 들어올 때 앞뒤 단어가 붙던 자동 줄바꿈 오류를 수정했습니다. 전투 대사 검사 폭은 204px로 맞추고, 상단 몬스터 알림의 216px 기준은 유지했습니다. V0.76 대사 검수 결과와 개별 배치 설정을 함께 제공합니다.

## 실행

1. 릴리스에서 `FF6-Korean-Text-Manager-V1.14-V0.76.zip`을 받습니다.
2. ZIP 전체를 쓰기 가능한 폴더에 풉니다. EXE만 따로 옮기지 마세요.
3. `FF6KoreanTextManager.exe`를 실행합니다.
4. 프로젝트 선택창이 나오면 `project-settings.json`과 `translations`가 들어 있는 압축 해제 폴더를 선택합니다.

**편집기는 번역 원본 JSON을 저장합니다. 이미 만들어진 BIN을 자동으로 고치거나 새 게임 이미지를 재빌드하지 않습니다.** 게임에 새 문장을 반영하려면 별도의 인코딩·삽입·이미지 생성과 실제 게임 검수가 필요합니다. 현재 배포 패처는 검증된 V0.76 고정 데이터를 적용합니다.

## 편집 흐름

1. 왼쪽 분류를 고르거나 원문·번역을 검색합니다. `#번호`로 ID를 찾을 수 있습니다.
2. 문장을 고르고 번역을 수정합니다.
3. 오른쪽 미리보기에서 원래 글꼴 크기·칸 폭·줄 수·줄 간격을 확인합니다.
4. 공백 표시와 격자로 반각 간격을 확인합니다.
5. `Ctrl+S`로 현재 문장을 저장하거나 수정분 모두 저장을 사용합니다.
6. `F5`로 전체 검사 후 검사표를 JSON/CSV로 내보냅니다.

큰 글씨 경로를 작은 글씨로 지정해 검사를 통과시키는 편집은 차단합니다. 자동 줄바꿈을 선택한 경우 검사한 줄바꿈을 저장할 수 있습니다. 동적 캐릭터 이름과 아이템·기술 이름은 예약 폭을 계산합니다. `printf` 형식의 수치 출력과 제어 코드 변경도 검사합니다.

## 기준값

| 영역 | 기본 검사 |
| --- | --- |
| 일반 대사 | 216px / 기본 4줄 / 줄 간격 16px |
| 프롤로그 | 실제 진행 폭으로 가운데 정렬 |
| 전투 큰 글씨 | 숫자·영문·문장부호를 포함해 12px, 공백 6px. 전투 대사 검사 폭 204px |
| 몬스터 한 줄 알림 | 상단 한 줄, 줄바꿈마다 다음 화면. 자동 줄바꿈 사용 안 함 |
| 도구 설명 | 216px / 2줄 |
| 환수 한 줄 요약 | 120px / 1줄 |
| 부록 설명 | 216px / 최대 6줄 |
| 작은 글씨 | 갈무리7, 글자 8px / 공백 4px |
| 영상 자막 | 12×12, 한 줄 304px / 2줄 / 줄 간격 14px |
| 갤러리 | 각 원본 페이지에 지정된 설명 사각형과 줄 수 |

개별 항목의 실제 경계가 확인되지 않은 경우 `참고`로 표시합니다. 화면 오른쪽 끝까지의 폭과 이웃 칸까지의 폭은 같지 않으므로 검사값을 해당 장면에 맞게 확정해야 합니다.

## 보존되는 제어 코드

`{char...}`, `{item...}`, `{key}`, `{pause}`, `{wait...}` 등은 일반 글자가 아닙니다. 이름 치환, 입력 대기, 타이밍, 페이지 처리에 사용됩니다. 특히 전투의 일부 `{key}`는 같은 줄 안에서 입력만 기다리므로 임의로 새 페이지로 계산하면 실제 게임과 어긋납니다.

영상 자막은 영화 ID와 시작/종료 프레임도 함께 관리합니다. 현재 등록된 29개 큐는 오프닝 24개와 엔딩 5개입니다. 오페라 가사 큐는 아직 없습니다.

## 백업과 충돌 검사

저장 전 기존 JSON을 `work/text-manager-backups/날짜-식별자/`에 보관합니다. 다른 프로그램이 파일을 수정했으면 충돌로 알려 덮어쓰기를 막습니다. 여러 문장을 일괄 가져올 때는 검사 후 함께 저장하고, 중간 저장 실패 시 이미 바뀐 파일을 복원합니다.

게임 ROM·메모리 카드·상태 저장의 백업 기능과는 별개입니다.

## 배포 데이터와 빠진 자료

ZIP에는 번역 원본, 배치 설정, 원문·분류 메타데이터, 편집기 EXE와 라이선스를 제공합니다. 원본 게임, 추출된 게임 실행 파일, 원본 갤러리 전체 이미지는 포함하지 않습니다.

갤러리의 원본 그림 위 미리보기는 로컬에서 `analysis/gallery-assets/`에 해당 원본 이미지를 준비했을 때 사용할 수 있습니다. 배포본에서도 글자 폭과 지정 사각형 검사는 가능하지만 원본 배경 비교는 제한됩니다. 실제로 없는 원본 이미지를 표시했다고 간주하지 마세요.

## 배포 시 검사 결과

7,720개 항목과 포함된 글꼴을 불러왔습니다. 전체 정적 검사에서 오류 등급은 0개였고, 아래 참고·주의가 남았습니다.

| 등급 | 항목 | 개수 |
| --- | --- | ---: |
| 참고 | 화면별 경계/높이 추정값 | 6,774 |
| 주의 | 기본 칸 높이 초과/스크롤 가능 구간 | 107 |
| 주의 | 연속 공백 | 17 |
| 주의 | 동적 문자열 | 8 |
| 주의 | 가변 수치 폭 | 10 |

주의 개수는 모든 항목의 실제 게임 오류 수를 뜻하지 않습니다. 반대로 오류 등급 0개도 전체 게임 화면이 검증됐다는 뜻은 아닙니다. [검사 요약 JSON](verification/text-manager-audit-summary.json)에 실제 집계를 보관했습니다.
