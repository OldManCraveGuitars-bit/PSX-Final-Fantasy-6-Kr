## V0.76 제보 수정과 문장 검수

- 새 디스크를 처음부터 부팅한 후 격리된 테스트 메모리 카드를 사용했습니다.
- 설정 두 페이지의 커서, 부스트 기본 OFF와 네 항목의 전환·복귀를 확인했습니다.
- 월드맵과 나르셰 탄광의 실제 세이브 포인트에서 텐트 소모, HP/MP 회복, 정상 복귀와 이동을 확인했습니다. 위치·아이템 수량은 테스트 조건이고 사용 허용 여부·코드·입력 처리는 원래 경로입니다.
- 금액 500/1000/1500, 콜츠산 대사 250, 필살기 설명 212–216은 해당 네이티브 출력기에서 문장을 선택해 확인했습니다. 그 이야기 구간 전체의 플레이 검증은 아닙니다.
- 유미르의 원래 대사 6–11과 몬스터 메시지 5, 전투 복귀도 확인했습니다.
- 본편·PSX 도움말·전투 문장/기술/대사 3,908개를 읽어 검수했습니다. 문구·줄바꿈 변경 1,237개, 검사 폭 변경만 248개입니다. 빈 항목·중복을 포함합니다.
- 최신 필드 스트림 3,100개와 전투 텍스트 1,758개를 MIPS 디코더로 대조했습니다. 필드 이름 128개와 사용자 이름·미확정 이름, 숫자 픽셀도 확인했습니다.
- 문장 관리기 회귀 검사 41개가 통과했습니다. 편집 원본은 EXE 일괄 가져오기로 저장했습니다.

## 배포 패처 검사

배포할 Windows x64 EXE 자체를 명령줄 모드로 실행했습니다.

- 내장 차분과 변환 도구 해시 확인.
- 지원 원본 → 완성 BIN 변환 및 최신 v086과 결과 해시 일치.
- CUE의 파일명과 트랙 형식 일치.
- 기존 출력 폴더 거부 및 그 안의 파일 보존.
- 크기가 다른 파일 거부.
- 크기가 같고 1바이트만 다른 원본도 SHA-256으로 거부.
- 이미 패치된 BIN 재적용 거부.
- 실패 시 완성 폴더 미생성.
- 원본 SHA-256 불변.
- 한글과 공백을 포함한 출력 경로 처리.

[실제 통합 검사 기록](verification/patcher-integration.json). 패처 GUI의 시각적 창 배치 검증은 이번 버전에서 별도로 수행하지 않았습니다. EXE 변환과 오류 처리 검사는 완료했습니다.
