# 확인된 제한과 남은 작업

V0.75-r1는 내부 개발본 v084에 기반한 공개 테스트 배포입니다.

## 번역·자막

| 항목 | 상태 |
| --- | --- |
| 오페라 영상 노래 가사 | 가사 판독과 프레임 타이밍 확인이 남아 있음. 미확정 가사 미삽입 |
| 정적 일본어/크레딧 이미지 일부 | 잔존 가능. 동영상 자체에 찍힌 원문은 별도 한국어 자막과 함께 보임 |
| 전투 마법 상세창 | `しょうひ MP` 기존 이미지 문구가 남아 있음 |
| 갤러리 작은 손글씨 메모 | 판독이 어려운 1곳 원문 보존 |
| 문맥·오타·조사 | 일괄 검수 반영. 게임 전체 맥락에서 추가 검수와 제보 필요 |

## 검증의 한계

- 엔딩까지 모든 이벤트와 전투, 모든 파티/아이템/장비 조합을 플레이하지 않았습니다.
- 기록된 실제 실행 검수는 별도 Mednafen 환경 중심입니다. 실기 및 모든 다른 코어/에뮬레이터에서 검증했다고 주장하지 않습니다.
- 네이티브 루틴 전수 검사, 폰트 픽셀 비교, 이미지 해시 검사와 전체 게임 실행 검증은 서로 다른 검사입니다.
- 문장 관리기의 폭·줄 수 검사는 텍스트 배치 검사입니다. 런타임의 텍스처 충돌, 비동기 전송, 장면 전환 문제까지 검출하지는 않습니다.
- 편집기의 기본 칸 높이·일부 경계는 추정값입니다. 표시되는 `참고`와 `주의`는 무시해도 된다는 뜻이 아닙니다. 실제 해당 화면을 보면서 확정해야 합니다.
- 메뉴 캐시는 조건에 맞는 장면에서만 작동합니다. 저장·이름 입력 후 또는 용량 초과 장면에서는 전체 다시 읽기가 발생할 수 있습니다.

## 기존 저장과 업데이트

상태 저장은 구버전 코드와 VRAM을 포함할 수 있으므로 새 CUE로 시작해 게임 내 저장을 불러오세요. 에뮬레이터가 새 파일명에 별도 카드를 연결할 수 있습니다. 패처는 기존 카드와 상태 저장을 이동·수정·변환하지 않습니다.

## 문제 제보

[Issues](https://github.com/OldManCraveGuitars-bit/PSX-Final-Fantasy-6-Kr/issues)에 아래 정보를 적어 주세요.

1. 사용한 공개 버전과 결과 BIN 해시. V0.75-r1의 내부 기준은 v085입니다.
2. 에뮬레이터/코어 이름과 버전, 일반 실행인지 상태 저장 복원인지.
3. 장소·파티·선택 메뉴·발생 직전 행동과 반복 여부.
4. 스크린샷 또는 짧은 재현 순서. 가능하면 어떤 글자가 기대되었는지도 기재.
5. 부스트 항목별 ON/OFF 상태.

원본 게임 이미지나 BIOS를 이슈에 첨부할 필요는 없습니다. 개인 정보가 있는 로그·파일 경로는 가리고 올려 주세요.
