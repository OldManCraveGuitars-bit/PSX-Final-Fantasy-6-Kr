# 세부 구현과 조작

## 한글 글꼴과 텍스트

큰 글씨를 작은 글씨로 바꾸어 칸에 맞추지 않고 기존 큰 글씨 경로를 유지했습니다. 메뉴·전투의 큰 글리프는 원래 12px 진행 폭과 12×11 비트맵을 사용하며, 부록·영상 자막에는 12×12 셀을 사용합니다. 작은 UI 글씨는 **갈무리7**, 작은 셀은 8×8입니다.

공백은 U+0020 반각 공백입니다. 큰 글씨·자막은 6px, 작은 글씨는 4px로 진행합니다. 프롤로그는 줄마다 실제 폭을 계산해 가운데 정렬합니다. 완결된 문장에는 마침표를 적용하고, 의문·감탄·말줄임표는 해당 문장에 맞게 유지합니다. 이름·제목·메뉴 항목에는 문장처럼 마침표를 붙이지 않습니다.

원래 영문 UI는 기본적으로 유지합니다. 오프닝 영상에 나오는 영문 문구·크레딧은 별도 한국어 자막을 추가한 예외입니다. 원본 영상 안에 이미 찍힌 영문/일문 글씨를 영상에서 지우는 방식은 아닙니다.

직업 명칭은 **모험가**로 표시하며, 대화 속 호칭은 **트레저 헌터**를 사용합니다. 메뉴·상태·저장 미리보기·부록의 직업과 대사를 분리해 관리합니다.

## 이름 작성기

- 캐릭터 이름을 정하는 게임 이벤트에서 기존 이름 입력창을 사용합니다.
- 패드로 자음·모음을 골라 한글 음절을 조합합니다.
- 최대 6글자이며 한글, 영문, 숫자, 공백을 혼용할 수 있습니다.
- 지우기는 종성 → 중성 → 초성 → 이전 글자 순으로 조합 단계를 되돌립니다.
- 이름은 대사·메뉴·전투·승리 메시지와 PSX 저장 목록 미리보기로 전달됩니다.
- 저장 목록은 각 파일의 이름 글꼴을 준비하므로 현재 파티 이름만으로 모든 저장 슬롯을 그리지 않습니다.
- 초반 주인공의 미확정 이름은 원판의 `??????` 상태를 유지합니다.

## 카이엔 필살검 이름

특수 → 필살검에서 기술을 고르면 원래 이름 변경 화면을 사용할 수 있습니다. 선택 가능한 원래 문자 249개를 한글 독음·영문·숫자·기호로 연결했습니다. 캐릭터 이름의 자모 조합 화면과는 별도 기능입니다. 이름 변경 칸은 커서 정렬을 위해 12px 셀을 유지하고 완성된 이름의 반각 공백은 6px로 표시합니다. 기본 8종과 변경한 이름은 기술 목록과 전투에서 같은 문자표를 사용합니다.

## 부스트

필드 메뉴의 **설정** 화면에서 **SELECT**를 누르면 부스트 페이지로 전환됩니다.

| 항목 | OFF | ON |
| --- | --- | --- |
| 인카운트 차단 | 원래 무작위 전투 | 필드/월드 무작위 전투 차단 |
| 경험치 ×5 | 원래 보상 | 전투 획득 경험치 5배 |
| 획득 GIL ×5 | 원래 보상 | 전투 획득 길 5배 |
| AP ×5 | 원래 보상 | 전투 획득 AP 5배 |

**기본값은 모두 OFF**입니다. 위/아래로 선택, 왼쪽 OFF/오른쪽 ON, 결정 버튼으로 전환합니다. 취소 또는 SELECT로 설정 화면으로 돌아갑니다. ON에 대한 별도의 장황한 안내 문장은 넣지 않았습니다.

변경은 즉시 반영되며 원래 메모리 카드 저장의 확장 영역에 보관합니다. 새 게임과 설정이 없는 기존 저장에는 모두 OFF를 적용합니다. 무작위 전투 차단은 시나리오 이벤트 전투를 제거하지 않습니다. 보상 배율은 원래 보상 계산 경로에 적용하므로 파티 경험치 분배 및 기존 장비 효과와의 순서가 존재합니다.

## 영상 자막

원본 STR 영상을 재인코딩하지 않았습니다. 영화 프레임 번호를 읽는 별도 런타임이 텍스트 큐를 선택하고 화면에 자막을 그립니다.

| 항목 | 설정 |
| --- | --- |
| 글자 셀 | 12×12 |
| 공백 폭 | 6px |
| 최대 줄 수 | 2줄 |
| 한 줄 최대 폭 | 304px |
| 줄 간격 | 14px |
| 기준 시간 | 원본 영상 15fps의 프레임 번호 |
| 현재 큐 | OPEN 24개, END 5개, 총 29개 |

오프닝의 지시문·타이틀·제작진 문구와 엔딩 영상의 문구를 지원합니다. **오페라 노래 가사 자막은 미완료**이며, 확정되지 않은 가사와 타이밍을 넣지 않았습니다. 큐를 수정하려면 문장 관리기의 동영상 자막 분류를 사용합니다.

## PSX 화면과 부록

저장·불러오기·임시 저장 확인창, 카드 선택 안내, 파일 미리보기의 이름과 직업, 기록 할아버지의 수치 표시, 청마법 도감과 콜로세움 표, 갤러리 설명을 다룹니다. 일본어 문자열을 한글로 치환하는 동시에 고정 버퍼의 길이와 배치, VRAM 전송 위치를 조정합니다.

갤러리는 설명 영역을 지정해 작은 글씨로 번역하며 주변 그림·테두리를 보존합니다. 현재 30페이지의 설명 176개 항목을 관리합니다. 판독 불가한 작은 손글씨 메모 1곳은 원문을 남겼습니다.

**부록 해금 조건은 원판 그대로입니다.** 새 게임부터 도감·영상·갤러리가 모두 열리도록 바꾸지 않았습니다. 설명용 스크린샷에서 열린 항목은 검사에 사용한 저장/검수 상태에 따른 것이며 시작 상태를 뜻하지 않습니다.

## 메뉴 로딩

자주 다시 쓰는 제한된 필드 데이터와 VRAM 영역을 보존해 메뉴에서 필드로 돌아올 때 복원합니다. 원본 CD의 모든 데이터를 RAM에 올리는 방식은 아닙니다. 이름 입력용 전체 글꼴은 이름 작성기를 사용할 때 적재합니다.

용량이나 장면 상태가 맞지 않으면 원래 읽기 경로로 돌아갑니다. 초반 메뉴 닫기의 감소는 측정되었으나 모든 메뉴 진입·복귀나 모든 에뮬레이터에서 같은 개선을 보장하지 않습니다. [측정 결과](TESTING.md)를 참고하세요.
