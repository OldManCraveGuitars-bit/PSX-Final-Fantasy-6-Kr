# V0.771 — 오프닝 자동 진행 멈춤 수정

내부 v088 기반의 공개 테스트 수정판입니다.

- **오프닝 진행 멈춤 수정:** 티나가 마도 아머 병사 쉰 명을 쓰러뜨렸다는 설명이 5줄로 늘어나, 원래 자동 진행 타이머 전에 버튼 입력을 기다리던 문제를 고쳤습니다. 이제 입력 없이 다음 대사로 넘어갑니다.
- **같은 원인 전수 검사:** 본편 3,084개와 PSX 보조 16개, 총 3,100개 대사의 자동 진행 구간 192개를 검사했습니다. 빌리·클라이드 회상에서도 같은 문제를 찾아 함께 수정했고, 해당 줄 넘침은 0개입니다.
- **문장 관리기 1.16:** 자동 진행 대사가 실제 216px·4줄을 넘으면 저장과 일괄 가져오기를 차단합니다. 화면 검사 폭을 넓혀도 이 검사는 유지하며, 빌드 단계에서도 확인합니다. 일반적인 버튼 스크롤 대사는 구분합니다.
- **기존 기능 유지:** 큰 글씨 12px, 반각 공백, 대사 타이머·제어 코드, 필살검 수정, 부스트와 원판 부록 해금 조건을 유지했습니다. 새 대사에 맞춰 필드 캐시를 갱신했습니다.

## 확인 범위

Mednafen에서 V0.77의 해당 대사를 1,900프레임 동안 입력 없이 기다려 멈춘 현상을 재현했고, 확인 버튼을 누르면 진행함을 확인했습니다. CPU 정지가 아니라 5번째 줄에서 타이머 전에 입력을 기다리는 문제였습니다. 수정 후에는 버튼 없이 다음 대사로 이어지며, 새 게임에서 나르셰 도착 및 메뉴 열기·닫기까지 확인했습니다.

회상 대사 ID 459는 같은 출력기에서 메시지 선택을 임시 변경해 4줄 표시와 자동 진행을 확인했습니다. 해당 회상 이벤트 전체를 플레이한 검증은 아닙니다. 모든 필드 대사 3,100개와 자동 진행 구간 192개를 정적으로 검사했고, 3,100개 스트림의 MIPS 디코드, 이름·카탈로그 경로, 편집기 46개 회귀 검사도 통과했습니다.

배포 패처 EXE의 실제 원본 적용·결과 해시·원본 보존·오류 처리도 검사했습니다. 제보의 DuckStation 환경 자체는 직접 재검증하지 않았습니다. 전체 게임 플레이 검증과 오페라 노래 가사 자막은 미완료입니다.
