# V0.77 — 카이엔 필살검 이름 및 관련 화면 수정

내부 v087 기반의 공개 테스트 버전입니다.

- **필살검 8종 공격명 복구:** 카이엔의 아·공·호·무·용·월·열·단을 모두 수정했습니다. 전용 저장 문자 코드를 일반 전투 글꼴로 잘못 읽던 경로를 고쳤습니다.
- **관련 메뉴 누락 수정:** 특수 메뉴의 필살검 목록, 이름 변경 미리보기와 선택 문자표까지 함께 한글로 연결했습니다. 이름을 바꾸면 전투에도 같은 글자가 나옵니다.
- **249개 선택 문자 연결:** 한자는 한글 독음으로, 원래 영문·숫자는 해당 문자로 표시합니다. 기존 6바이트 이름 저장 형식과 저장 데이터는 유지합니다.
- **문장 관리기 1.15:** 필살검 문자표 249개를 추가해 총 7,969개 항목을 관리합니다. 한 글자 제한과 고정 공백을 검사합니다.
- **기존 수정 유지:** 텐트·설정 커서·금액·대사 검수, 메뉴 캐시, 부스트와 원판 부록 해금 조건은 그대로 이어집니다. 큰 글씨 12px와 반각 공백을 유지했습니다.
