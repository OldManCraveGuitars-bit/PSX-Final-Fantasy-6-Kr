# 실제 실행 스크린샷

총 18장입니다. 원본 캡처의 비율과 픽셀을 유지했습니다. 공개 V0.75의 내부 기준은 v084이며, 이전 개발 단계에서 같은 기능을 검수한 사진도 포함합니다. 각 사진에 내부 촬영 번호를 적었습니다.

부록 해금 상태와 파티 구성은 검수용 상태에 따릅니다. 새 게임에서 모두 열려 있거나 사진과 같은 파티로 시작한다는 뜻은 아닙니다.

![록 직업 · 트레저 헌터](screenshots/locke-job.png)

## 05. 적 공격명 · 엄니 전체 표시

![적 공격명 · 엄니 전체 표시](screenshots/enemy-fang.png)

촬영 원본: `v084-native-enemy-special-25.png`.

원래 늑대 AI가 엄니를 쓰는 레벨 조건(7 초과)을 맞추기 위해 검수 RAM에서 파티 레벨을 8로 설정했습니다. 공격/AI 코드나 배포 시작 레벨은 변경하지 않았습니다.
