FF6 한글 문장 관리기 1.15

FF6KoreanTextManager.exe를 실행하세요. 별도 Python 설치는 필요 없습니다.
EXE가 있는 FF6 한글화 프로젝트 폴더를 자동으로 엽니다.
다른 곳으로 EXE만 복사한 경우 '프로젝트 열기'로 원래 프로젝트 폴더를 선택하세요.

1. 분류·상태·검색으로 문장을 고릅니다. #6처럼 입력하면 ID로 찾습니다.
2. 원문 옆에서 한글 번역을 수정합니다. {page}, {char00} 등은 보존합니다.
3. 화면 기준을 고르고 폭·줄 수·줄 간격을 확인합니다. 미리보기에서 빨간 선이 칸 끝입니다.
4. Ctrl+S로 현재 항목, Ctrl+Shift+S로 수정분 전체를 저장합니다.
5. F5로 전체 검사합니다. 문제 행을 두 번 누르면 해당 문장으로 이동합니다.
6. 검사표는 CSV/JSON으로 내보낼 수 있습니다.
7. '일괄 가져오기'로 JSON 문장 묶음을 불러온 뒤 수정분 모두 저장을 누를 수 있습니다.
   모든 항목을 먼저 검사하고, 문제가 없을 때 하나의 백업을 만들고 함께 저장합니다.
   가져올 JSON은 다음 형식의 배열입니다.
   [{"uid":"translations/manual_dialogue.json:1001","translation":"수정한 문장.","reviewed":true}]
   source 필드를 함께 넣으면 일본어 원문까지 일치하는지 검사합니다.

큰 글씨는 원래 12px, 작은 글씨는 갈무리7 / 8px, 자막은 12×12 기준입니다.
반각 공백은 큰 글씨 6px, 작은 글씨 4px입니다. 전각 공백과 탭은 오류로 표시합니다.
부스트 설정 분류에는 부스트 화면과 마법 정렬의 보충 글씨가 있습니다.
항목명·ON/OFF·마법 분류별 고정 칸을 넘거나 줄바꿈을 넣으면 저장하지 않습니다.
줄 끝 공백, 연속 공백, 미완성 자모, 제어 코드 손상, 일본어 잔여, 마침표 누락 후보도 검사합니다.
여러 줄로 나뉜 선택지는 마침표 검사에서 제외하며, 선택지 뒤의 본문은 계속 검사합니다.
전투 큰 글씨는 영문·숫자·문장부호도 고정 12px로 검사합니다.
전투 대사는 오른쪽 테두리 여유를 두어 204px로 검사합니다. 몬스터 상단 메시지는 기존 216px입니다.
1.14부터 줄 끝에서 넘친 공백 때문에 다음 단어가 붙는 문제를 수정했습니다.
전투의 {key}는 줄을 바꾸지 않는 입력 대기입니다. 앞뒤 문장의 폭을 합쳐 검사합니다.
미리보기의 노란 점선은 입력 대기 위치이며, 글자 폭이나 별도 쪽을 차지하지 않습니다.
몬스터 메시지는 상단 한 줄씩 넘어가는 실제 방식으로 미리봅니다. 줄바꿈마다 다음 화면이며,
{pause} 같은 대기 코드는 글자 폭에 포함하지 않습니다. 이 경로의 자동 줄바꿈은 막습니다.
설명문은 도구·마법 216px/2줄, 환수 요약은 120px/1줄 기준으로 시작합니다.
부록 몬스터 설명은 실제 삽입기처럼 문단을 이어서 단어 단위로 줄바꿈합니다.
캐릭터 이름은 최대 6글자, 도구·마법·몬스터 등은 현재 번역 목록의 최장 폭을 예약합니다.
캐릭터 기본 이름도 반각 공백을 포함해 6글자까지만 저장할 수 있습니다.
이 이름은 본편·전투·저장 미리보기에 함께 반영됩니다.
실행 중 내용이 달라지는 일반 서식 변수(%s, %d 등)는 별도 주의를 표시합니다.
PSX 작은 글씨는 화면 폭 외에 원래 고정 문자열의 저장 용량도 검사합니다.
저장 용량을 넘으면 글씨 크기를 유지하고 문구를 줄여야 하며, 저장을 막습니다.
예·아니요 같은 응답 선택지에는 마침표 누락 경고를 표시하지 않습니다.

'삽입 시 자동 줄바꿈'을 켜고 저장하면 검사 폭에 맞춘 줄바꿈도 번역 파일에 저장합니다.
폰트 선택과 줄 간격은 검사할 출력 경로의 기준입니다. 게임의 글꼴 크기를 바꾸지는 않습니다.
대사 폭 216px, 부록 설명 216px/6줄, 자막 각 줄 304px/최대 2줄은 현재 삽입기의 기준입니다.
자막은 12×12, 줄 간격 14px이며 각 줄을 가운데 정렬합니다.
화면마다 폭이 다른 메뉴·설명문은 추정 영역으로 시작합니다. 실제 경계를 확인하고
'실제 칸 경계 확인 완료'를 체크하면 항목마다 검사 영역을 저장할 수 있습니다.
문장이 여러 화면에서 쓰이면 해당 출력 경로마다 검사하세요.
영문·아이콘 모양은 출력 경로별 차이가 있을 수 있습니다.
텍스트 검사는 그래픽·VRAM 안전성을 보장하지 않습니다. 최종 게임 실행 검사는 별도로 합니다.

편집 대상: 대사, PSX 도움말, 설명문, 전투 문장·기술, 이름·도구·마법,
메뉴·직업, 지역명, 부록 문장·작은 글씨, PSX 저장·불러오기·작은 글씨.
동영상 자막은 목록에서 번역을 수정합니다. 상단에 영상 이름과 시작·끝 프레임/초가 표시됩니다.
'자막 등록'에서 전체 자막 JSON 목록을 등록하거나 타이밍을 갱신할 수 있습니다.
각 항목은 movie(OPEN/OPERA), start_frame, end_frame, source, translation을 포함합니다.
프레임은 15fps 원본 동영상 기준이며 끝 프레임은 표시하지 않습니다.
등록·저장 때 줄 폭, 두 줄 제한, 시간 중복, 영상별 글꼴·문장 용량도 검사합니다.
전체 목록 등록은 기존 자막 목록을 교체하며 자동 백업을 남깁니다.

메인 대사에서 '검수 완료'를 체크하면 manual_dialogue.json에 저장합니다.
체크를 풀면 dialogue.ko.json 초안에 저장하며 검수본에서는 제외합니다.
부록 문장은 omake.ko.json과 omake-manual.json을 함께 갱신합니다.
그 외에는 화면에 표시된 원본 번역 JSON을 갱신합니다.
수정 내용은 다음 ROM 빌드에 반영됩니다. EXE 자체는 디스크 이미지를 수정하지 않습니다.

저장 전 원본 백업: work/text-manager-backups/날짜-시각/
검사 영역: translations/text-manager-layouts.json
검수 상태: translations/text-manager-status.json
외부에서 바뀐 파일은 덮어쓰지 않고 충돌을 알립니다.
저장 중 프로그램이 강제 종료되어 잠금 파일이 남으면 다른 관리기가 저장 중인지 확인한 뒤
translations/.text-manager-save.lock 파일을 제거하고 다시 실행할 수 있습니다.

명령줄 검사(개발용):
FF6KoreanTextManager.exe --audit 검사표.json
FF6KoreanTextManager.exe --project 프로젝트폴더 --audit 검사표.csv
FF6KoreanTextManager.exe --apply-batch 문장묶음.json --report 가져오기검사표.json
FF6KoreanTextManager.exe --import-subtitles 전체자막목록.json --report 자막검사표.json

아직 전체 한글화가 완료된 상태는 아닙니다. 초안과 미확인 출력 경로는 검사가 더 필요합니다.

1.15: 필살검 글자표 249개 추가. 한 글자 제한과 반각 공백 고정을 검사합니다. 자세한 내용은 docs/TEXT_MANAGER.md를 참고하세요.
